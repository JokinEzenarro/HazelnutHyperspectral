# NIR-HSI Dataset for In-Bag Hazelnut Oxidation Monitoring

This repository contains the dataset used in the study *NIR-HSI for the non-destructive monitoring of in-bag hazelnut oxidation*. The data support research on non-destructive assessment of hazelnut oxidation using near-infrared hyperspectral imaging (NIR-HSI).

## Dataset overview

Shelled `Ribeta` hazelnuts were packaged in bags of 12 nuts and monitored for 78 days. The experiment comprises 18 bags representing:

- Atmosphere: air, nitrogen, and vacuum
- Light exposure: light and dark
- Replicates: three per atmosphere-light combination

Each bag was imaged at 23 time points using a line-mapping NIR hyperspectral camera covering 1000-1600 nm at 142 wavelengths. The dataset may include bag-level images/spectra, individual-hazelnut segmentations, and associated experimental metadata.

## Purpose

The dataset enables investigation of how storage time, packaging atmosphere, and light exposure affect hazelnut oxidation, including variability among individual nuts and spatial oxidation patterns within their surfaces.
